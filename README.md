# CRUD_PRACTICE

A beginner-friendly **Student Management CRUD application** built using **HTML, CSS, and JavaScript**.

## ✨ Features

- Add student records
- Display student records in a table
- Edit existing student information
- Delete student records

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Structure |
| CSS3 | Styling |
| JavaScript | CRUD logic |
